# Mast Pharmacy - Full Stack Web Application

Mast Pharmacy is a complete management application for multi-clinic pharmacy operations.

## Project Structure (Monorepo)

- `backend/`: Node.js & Express API backend connected to MongoDB.
- `frontend/`: React single-page application with responsive UI and route protection.

## Deployment Details

- **Frontend Hosting**: Netlify (`frontend/` base directory)
- **Backend Hosting**: Render.com (`backend/` root directory)

## Features Included

- Multi-clinic sales entry & date-based sales tracking
- Admin & Clinic Worker role-based authorization
- Live global settings & price visibility controls
- Single-click Admin remote worker session invalidation
- Protected route redirection & custom UI styling
